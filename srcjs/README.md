# srcjs

Source for the `arcgisChart` htmlwidget. See
[`dev-docs/js-widget-architecture.md`](../dev-docs/js-widget-architecture.md) for
the full data flow, deferred items, and build commands
(`bun run development` / `production` / `watch`).

Quick orientation:

- `config/*.json` - read by `../webpack.common.js` (entry points, output
  path, externals, loaders). Edit these, not `webpack.common.js` itself,
  to add a new widget entry point.
- `widgets/arcgisChart.js` - the actual htmlwidgets JS binding.

Bundled output goes to `../inst/htmlwidgets/` - never hand-edit anything
there, it's regenerated by the build.
