# srcjs

Source for the `arcgisChart` and `arcgisMap` htmlwidgets. See
[`dev-docs/js-widget-architecture.md`](../dev-docs/js-widget-architecture.md) for
the chart data flow and
[`dev-docs/map-components-plan.md`](../dev-docs/map-components-plan.md) for the
map one, plus the build commands (`bun run development` / `production` /
`watch`).

Quick orientation:

- `config/*.json` - read by `../webpack.common.js` (entry points, output
  path, externals, loaders). Edit these, not `webpack.common.js` itself,
  to add a new widget entry point.
- `widgets/arcgisChart.js` - `<arcgis-chart>`, built from a `WebChart` config
  merged over `createModel()`'s own defaults.
- `widgets/arcgisMap.js` - `<arcgis-map>`, built from client side
  `FeatureLayer`s. The element takes live `@arcgis/core` objects, not JSON,
  so this one converts rather than merges.

Bundled output goes to `../inst/htmlwidgets/` - never hand-edit anything
there, it's regenerated by the build.
