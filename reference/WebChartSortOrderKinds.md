# WebChartSortOrderKinds

One of `"ASC"`, `"DESC"`, `NA`.

## Usage

``` r
WebChartSortOrderKinds(value = NA_character_)
```

## Arguments

- value:

  String. One of `"ASC"`, `"DESC"`, `NA`.

## Value

An object of class `WebChartSortOrderKinds`.

## Additional properties

- `@variants`:

  Character vector. The values this enum allows.

- `@allow_na`:

  Bool. Whether `NA_character_` is allowed.
