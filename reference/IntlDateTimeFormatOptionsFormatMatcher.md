# IntlDateTimeFormatOptionsFormatMatcher

One of `"basic"`, `"best fit"`, `NA`.

## Usage

``` r
IntlDateTimeFormatOptionsFormatMatcher(value = NA_character_)
```

## Arguments

- value:

  String. One of `"basic"`, `"best fit"`, `NA`.

## Value

An object of class `IntlDateTimeFormatOptionsFormatMatcher`.

## Additional properties

- `@variants`:

  Character vector. The values this enum allows.

- `@allow_na`:

  Bool. Whether `NA_character_` is allowed.
