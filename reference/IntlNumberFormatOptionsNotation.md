# IntlNumberFormatOptionsNotation

One of `"compact"`, `"engineering"`, `"scientific"`, `"standard"`, `NA`.

## Usage

``` r
IntlNumberFormatOptionsNotation(value = NA_character_)
```

## Arguments

- value:

  String. One of `"compact"`, `"engineering"`, `"scientific"`,
  `"standard"`, `NA`.

## Value

An object of class `IntlNumberFormatOptionsNotation`.

## Additional properties

- `@variants`:

  Character vector. The values this enum allows.

- `@allow_na`:

  Bool. Whether `NA_character_` is allowed.
