``` r
WebChartStackedKinds(value = NA_character_)
```

- value:

  String. One of `"sideBySide"`, `"stacked"`, `"stacked100"`, `NA`.

## Value

An object of class `WebChartStackedKinds`.

  Character vector. The values this enum allows.

- `@allow_na`:
