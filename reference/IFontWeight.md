# IFontWeight

One of `"bold"`, `"bolder"`, `"lighter"`, `"normal"`, `NA`.

## Usage

``` r
IFontWeight(value = NA_character_)
```

## Arguments

- value:

  String. One of `"bold"`, `"bolder"`, `"lighter"`, `"normal"`, `NA`.

## Value

An object of class `IFontWeight`.

## Additional properties

- `@variants`:

  Character vector. The values this enum allows.

- `@allow_na`:

  Bool. Whether `NA_character_` is allowed.
