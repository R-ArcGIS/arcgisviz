# The tags the Esri ramps are labelled with

Every distinct tag across all ramps, sorted. These are what
[`esri_palettes()`](http://r.esri.com/arcgisviz/reference/esri_palettes.md)'s
`tag` argument accepts.

## Usage

``` r
palette_tags()
```

## Value

A character vector of tags.

## Examples

``` r
palette_tags()
#>  [1] "3d"                  "blues"               "bright"             
#>  [4] "browns"              "categorical"         "centered-on"        
#>  [7] "colorblind-friendly" "dark"                "diverging"          
#> [10] "esri-brand"          "extremes"            "grays"              
#> [13] "greens"              "group-similar"       "heatmap"            
#> [16] "light"               "lines"               "oranges"            
#> [19] "pinks"               "point-cloud"         "purples"            
#> [22] "reds"                "sequential"          "subdued"            
#> [25] "yellows"            
```
