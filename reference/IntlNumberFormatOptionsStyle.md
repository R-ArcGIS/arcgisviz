# IntlNumberFormatOptionsStyle

One of `"currency"`, `"decimal"`, `"percent"`, `"unit"`, `NA`.

## Usage

``` r
IntlNumberFormatOptionsStyle(value = NA_character_)
```

## Arguments

- value:

  String. One of `"currency"`, `"decimal"`, `"percent"`, `"unit"`, `NA`.

## Value

An object of class `IntlNumberFormatOptionsStyle`.

## Additional properties

- `@variants`:

  Character vector. The values this enum allows.

- `@allow_na`:

  Bool. Whether `NA_character_` is allowed.
