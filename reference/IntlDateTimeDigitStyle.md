# IntlDateTimeDigitStyle

One of `"2-digit"`, `"numeric"`, `NA`.

## Usage

``` r
IntlDateTimeDigitStyle(value = NA_character_)
```

## Arguments

- value:

  String. One of `"2-digit"`, `"numeric"`, `NA`.

## Value

An object of class `IntlDateTimeDigitStyle`.

## Additional properties

- `@variants`:

  Character vector. The values this enum allows.

- `@allow_na`:

  Bool. Whether `NA_character_` is allowed.
