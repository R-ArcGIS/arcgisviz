# WebChart

WebChart

## Usage

``` r
WebChart(
  version = NA_character_,
  type = NA_character_,
  id = NA_character_,
  dataFilters = NULL,
  title = NULL,
  subtitle = NULL,
  footer = NULL,
  background = NULL,
  cursorCrosshair = NULL,
  legend = NULL,
  axes = list(),
  horizontalAxisLabelsBehavior = WebChartLabelBehavior(),
  verticalAxisLabelsBehavior = WebChartLabelBehavior(),
  series = list(),
  rotated = NA,
  stackedType = WebChartStackedKinds(),
  colorMatch = NA,
  chartRenderer = NULL,
  orderOptions = NULL,
  iLayer = NULL
)
```
