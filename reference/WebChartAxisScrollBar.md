# WebChartAxisScrollBar

WebChartAxisScrollBar

## Usage

``` r
WebChartAxisScrollBar(
  visible = NA,
  width = NA_real_,
  color = NULL,
  gripSize = NA_real_,
  margin = NA_real_
)
```

## Arguments

- visible:

  Bool.

- width:

  Number.

- color:

  `NULL` or a `Color` object.

- gripSize:

  Number.

- margin:

  Number.

## Value

An object of class `WebChartAxisScrollBar`.

## Examples

``` r
WebChartAxisScrollBar(visible = TRUE, width = 12, gripSize = 6)
#> <arcgisviz::WebChartAxisScrollBar>
#>  @ visible : logi TRUE
#>  @ width   : num 12
#>  @ color   : NULL
#>  @ gripSize: num 6
#>  @ margin  : num NA
```
