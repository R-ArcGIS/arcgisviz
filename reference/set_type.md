# Set a chart's type

Set a chart's type

## Usage

``` r
set_type(chart, type)
```

## Arguments

- chart:

  An `ArcChart`, from
  [`arc_chart()`](http://r.esri.com/arcgisviz/reference/arc_chart.md).

- type:

  One of `"bar"`, `"scatter"`, `"line"`.

## Value

`chart`, with a fresh single series of the matching type.
